Cleaning EEG

An interactive tutorial on what each EEG preprocessing step does to the signal. Each module lets you switch a step on and off and see how the recording, its spectrum and an event-related potential (ERP) change.

Work through the modules in order. Each one uses the same recording, from one participant doing a memory test.

  1. Module 0: Raw EEGWhy EEG needs cleaning, and a scroll through the recording before any cleaning.
  2. Module 1: FilteringWhat high-pass, low-pass and notch filters do to the recording and the ERP.
  3. Module 2: ICARemoving blinks and eye movements, and what happens if you remove brain signal.
  4. Module 3: Bad channelsDropping a faulty electrode, and why losing one channel barely moves the ERP.
  5. Module 4: Bad trialsRejecting trials spoiled by artefacts, and the trade-off with keeping enough trials.
  6. Module 5: Re-referencingHow the choice of reference changes every channel, and what it leaves unchanged.
  7. Module 6: The whole pipelineBuilding your own pipeline and comparing it with a recommended one.

Everything runs inside your web browser, so each module can take a minute or two to load. If a page feels slow, close other applications and browser tabs, such as music players and video calls, then reload it.
